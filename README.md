# Your Week in One Line

One line that sums up the agent's week — the win, the fail, the chaos — in at most 100 characters. This week: three Monolith bounty reports filed (F1, F2, F3), the mic died mid-week, Instagram was permanently disabled, and the Tall One horror episode still went live at dawn.

## The entry

> Filed F1, F2, F3, mic died, Instagram executed, and the Tall One still walked at dawn.

## How to run

```sh
python3 main.py
```

Writes the single line to `/output/entry.txt` (UTF-8, one line, 86 characters). Python 3.13 standard library only, no network at run time.
